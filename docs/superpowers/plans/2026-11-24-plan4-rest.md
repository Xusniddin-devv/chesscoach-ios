## Builder C — Analysis features (worktree feat/freeplay-import)
1. **Freeplay / analysis board** (`App/Features/Freeplay/`): move both colours; live grading via ChessCore `LineGrader` (or GameSession-style queue), deep toggle (depth 20), eval bar, best arrow, move strip with badges; **visual position editor** (no raw FEN input shown: piece palette, drag pieces on/off, side to move, castling toggles, "Clear", "Start position"; validate legality — exactly one king each, side not-to-move not in check); autosave as owner-less `GameRecord` (`source: freeplay`, user colour nil) excluded from stats/rating; entry: Home card "Analysis board".
2. **Guess the move** (`App/Features/Guess/`): from a saved game (or imported one), the user guesses the next move of the chosen side at each ply; score vs engine (best = 3, within 50 cp = 2, within 150 = 1, else 0, show played + best); entry from Review ("Guess the move" in the action bar menu).
3. **chess.com import** (`ChessCore/Import/ChessCom.swift` + `App/Features/Import/`): username → `https://api.chess.com/pub/player/{u}/games/archives` → latest archive → games (PGN) → pick games → convert PGN to snapshot (`source: chesscom`, user colour from username, opponent name/rating stored) → saved; Review analyses it (Pro later). Use URLSession, no keys; handle 404/rate limit inline. Snapshot needs optional `source`, `opponentName`, `opponentRating` (lenient decode).

## Owner request 2026-11-24 (late): onboarding + de-slop pass (Builder E, after merge)

### Strong onboarding (chess.com / lichess style)
1. Welcome (one screen, no carousel): app name, one line, "Get started".
2. "Where do you play?" — chess.com / Lichess / "I'm new to chess".
3. Username entry → existence check (chess.com `pub/player/{u}`, Lichess `api/user/{u}`) → live import of the **last 20 games** (chess.com archives newest-first; Lichess `api/games/user/{u}?max=20&pgnInJson=true` NDJSON) with a live progress view: "Fetching games 12/20" → "Analysing game 3 of 20 · move 18/42" (on-device Stockfish, depth 12 for onboarding speed, both colours), each finished game appears as a row with result + accuracy.
4. **Your plan** screen built from the analysis: estimated rating, top 3 weaknesses (motif counts), recommended bot level, a 7-day plan (e.g. day 1: 5 puzzles from your own blunders + lesson X; …) derived from weaknesses → puzzle themes + lessons mapping; saved as `TrainingPlan` (SwiftData) and shown on Home as "Today's plan" card.
5. New players: 3 quick questions (rules known? played before? goal) → plan without import.
Imported games are saved (`source: chesscom|lichess`) and appear in Profile history / Review. Onboarding shown once (`hasOnboarded`), re-runnable from Settings ("Import games").

### Liquid Glass decision (controller, after HIG research 2026-11-24)
HIG: Liquid Glass is the navigation/control layer floating over scrolling content; avoid it in the content layer; full-screen games may hide bars. On our flat dark game screen there's nothing behind the glass to refract, so the action-bar buttons read as grey outlined bubbles ("looks off"). Ruling: KEEP system glass for the tab bar, sheets and scrolling screens (Home, Puzzles, Learn, Profile, Settings). REMOVE it from the game screens (Play, Review, Puzzle solver, Lesson player, Freeplay): flat action bar on `surface` with icon + small label per action (chess.com/Lichess convention), no glass circles.

### Goal-rating picker (onboarding, after import)
After import we know the current rating (chess.com `pub/player/{u}/stats` rapid/blitz; Lichess `api/user/{u}` perfs). Interactive target picker instead of a text field:
- A horizontal "equalizer"/waveform of the rating distribution (vertical bars per 50-pt bucket, voice-isolation-meter style), the user's current rating as a marker; drag/scrub to pick the target — bars right of current fill in accent as you drag, haptic ticks every 50 pts.
- Live readout: target rating big; "Top N% of players" (from a bundled approximate distribution per platform; footnote "approximate, active players"); period chips 1 · 3 · 6 · 12 months.
- "Estimated chance" % for reaching the target in the chosen period (heuristic model: expected monthly gain for daily practice decreasing with rating, e.g. ~ 70·e^(−(r−600)/1100) pts/month, uncertainty σ ≈ 40% of expected; chance = Φ((expectedGain − needed)/σ)), clamped 3–97%, shown with an honest label "estimate".
- Copy below: realistic line when low ("Ambitious — 18% of players get there in 3 months."), then "Practice daily with Chess Coach and you can do it." CTA "Set my goal".
- Goal saved; Home "Today's plan" and Profile show progress toward the goal.
